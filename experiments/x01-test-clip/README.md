## 規則問題（要使用者裁決）

**把卡上的數字代進卡上的公式，算出結果給觀眾看，算不算「自行推算新數字」？**

例子：k = 60（c6）代進 1 ÷ (k + 名次)（c5），A 的分數是 1/63 + 1/63。三次嘗試都刻意不算出小數，只照卡上 c9 說「常常是 A 贏」，長條標「示意」。

- 允許：可以「把數字算給觀眾看」（PoC 的強項），但要標「依卡上公式計算」，並由查核員驗算。
- 不允許：機制段落只能用示意數字。

## 回饋與決定

（使用者回覆後填入，並把定案的數值寫進 `config/style.json`。）

使用者 2026-11-07 的回覆：
- 手機上看影片沒有問題。
- **字級**：A～D（0.024～0.034）在手機橫向看偏小，下限定為 **0.038**，寫入 `config/style.json` 的 `min_text_frac`，`kit.py` 的預設字級也一起調高。
  這支測試片是在舊下限 0.03 時做的，用新規則重渲會報「字太小」。這是預期的，測試片不再更新。
- **配色**：照建議。移除 7 號淺黃；橘、粉不要和「錯誤」紅放在同一個畫面。
- **代入計算**：允許把卡上的數字代進卡上的公式算給觀眾看（觀眾比較好理解）。畫面標「依卡上公式計算」，查核紀錄寫 `calc`，由 `lib/checks/claims.py` 驗算。
- **TTS**：使用者有 OpenRouter 金鑰。查證後發現 OpenRouter 上的 Gemini 3.8 TTS 不支援聲音複製，見 `rules/external-rules.md`。

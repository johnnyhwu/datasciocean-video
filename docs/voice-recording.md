# 錄音稿：建立旁白的複製聲音

需要錄兩段音：**參考錄音**和**同意聲明**。錄好後放進 `assets/voice/`（不進 git），再執行 `uv run python lib/voice_create.py assets/voice/reference.wav assets/voice/consent.wav`。規格見 `rules/external-rules.md`「Gemini 3.8 Flash TTS 聲音複製」。

## 錄音前

- 安靜的房間，關掉冷氣、風扇。不要放音樂。
- 兩段都用**同一支麥克風、同一個房間、同一個距離**（嘴巴離麥克風約一個拳頭到 20 公分）。
- 存成 WAV 最好（手機的錄音 App 存 m4a 也可以，程式會轉檔）。**不要加降噪、等化器、變聲或背景音樂**。
- 錄完頭尾各留 0.5 秒安靜。中間念錯就整段重錄，不要剪接。
- 語氣就是影片要的語氣：像在跟朋友講一個有趣的發現，清楚、有精神，速度跟平常說話一樣，不用刻意播音腔。

## 1. 參考錄音 `reference.wav`（10～30 秒，選一段念）

**A 段（建議，約 25 秒）**

> 你有沒有遇過這種情況？明明答案就在資料庫裡，搜尋系統卻把它排到第四名。
> 今天我們來看一個很簡單的方法，叫做 RRF。它不看分數，只看名次：第一名拿最多，第二名少一點，再把兩份清單加起來。
> 聽起來很普通，對吧？但效果好得出乎意料。

**B 段（A 段念不順再用，約 22 秒）**

> 假設你有兩個搜尋引擎，一個懂意思，一個認關鍵字。
> 它們各自給你一份前十名的清單，可是分數的單位完全不一樣，一個是零點八，一個是十五。
> 那要怎麼合在一起？我們來舉個例子，一步一步算給你看。

兩段都有問句、數字和英文縮寫，這些都是旁白常出現的念法。

## 2. 同意聲明 `consent.wav`（照念，一字不改）

Google 的同意聲明中文只有簡體版，用平常的口音念就可以。念**中文版或英文版其中一個**：

> 我是此声音的拥有者并授权谷歌使用此声音创建语音合成模型。

> I am the owner of this voice and I consent to Google using this voice to create a synthetic voice model.

## 之後的步驟

1. 建立聲音要走 Gemini 直連（`.env` 要有付費層的 `GEMINI_API_KEY`；OpenRouter 不能複製聲音）。
2. 建好後先用同一句合成三個版本：你的複製聲音、Zubenelgenubi、你的原始錄音，給你盲聽定案。
3. 定案後才合成全片旁白（約 US$0.09）。

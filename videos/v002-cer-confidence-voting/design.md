# v002 設計紀錄：一張選票

## 一張大圖

機制的形狀是「同一個問題 → 好幾條平行的推理 → 一次表決」。所以大圖是一張由左到右的選票：

```
            ①        ②        ③
 問題 ──┬─ 500 ──── 125 ──── 375 ─ 分數 ┐
        ├─ 500 ──── 100 ──── 400 ─ 分數 ┤
        ├─ 500 ──── 125 ──── 375 ─ 分數 ┼──►  天平（左盤 375 ／ 右盤 400）
        ├─ 500 ──── 125 ──── 375 ─ 分數 ┤
        └─ 500 ──── 100 ──── 400 ─ 分數 ┘

 工作台 1（主圖下方左）：第二步那句話的 token 與機率     工作台 2（主圖下方右）：數學與問答、兩根提升幅度
```

- **主角**：正確答案 400。它票比較少，金色只給它（答案卡、右盤、最後的讀數）。
- **觀眾一路跟著的量**：信心。每一步底下一根紫色長條，長度就是信心；票的大小就是路徑的分數；天平的傾斜由兩邊的總和即時算出來。
- **開頭和結尾**：開場天平沉向 375（三顆一樣大的票）；結尾同一座天平沉向 400（兩顆大的票）。

## 鏡頭路線

| 場 | 鏡頭 | 發生的事 |
|---|---|---|
| sc01 | 近拍天平 | 五顆票落下，沉向 375；錘錘「？」；CER 三個字寫在橫樑上 |
| sc02 | 拉遠到全圖 | 問題卡、五條路徑畫出來，脈衝走過三步；步驟標題與中間答案寫上 |
| sc03 | 停在全圖 | 穩的路徑和晃的路徑各算一票；三條錯的同時閃 |
| sc04 | 往下鑽到工作台 1（最近的特寫） | token 一塊一塊寫出、機率長條、平均線、變暗只剩關鍵字、相乘 |
| sc05 | 回到最上面那條路徑（中景） | 三根信心長條、權重、加權平均算出 0.57 |
| sc06 | 拉回全圖 | 五個分數出現，票變成不同大小，天平翻向 400；錘錘「！」 |
| sc07 | 全圖 → 工作台 2 | 只留最後一步，天平翻回 375 再翻回來；數學對問答；兩根提升幅度 |
| sc08 | 全景 | 三點回顧：① 框天平 ② 框第二步那一欄 ③ 框信心長條與分數；錘錘；片尾動畫 |

## 會變的量（都由 tracker 驅動）

- 天平：兩盤各有一個總和 tracker，傾角 = clip((右 − 左) × 係數)。SC 模式下每票重量 1；CER 模式下是分數；CER-LAST 模式下是最後一步的信心。三種模式之間是同一組 tracker 平滑過去。
- 票的半徑 ∝ √重量（面積代表重量）。
- 工作台 1 的平均線：由目前算進平均的 token 機率算出來。

## 第二版（使用者 2026-11-17 看完第一版成片）

**回饋（原話）：**「動畫不夠有趣活潑」「內容解釋不夠清楚，剛開始說只看最後，後面又說要看過程，最後才說過程其實只看關鍵字，觀眾會有點 confused」。

**找到的原因：**

- 講解由小到大（token → 步驟 → 路徑 → 投票），觀眾到最後才知道前面的零件做什麼用；「看最後」對「看過程」分散在三處，CER-LAST 的對照還在結論之後回頭講。
- 動態量和 v001 差不多（每 0.2 秒有變動的畫面面積平均 0.65% 對 0.59%），所以不是動得太少，而是沒有帶情緒的角色：主題是「猶豫」，卻只畫成方框下的一條細橫條；錘錘只出場 3 次；沒有誇張的畫面。

**修改：**

1. **講解順序改成由大到小，一場只回答上一場留下的一個問題。**

   | 場 | 回答的問題 | 留下的問題 |
   |---|---|---|
   | sc01 五票 | （鉤子）三票該贏兩票嗎 | 猶豫的票怎麼辦 |
   | sc02 多數決怎麼做 | 原本怎麼投 | — |
   | sc03 每一票都一樣重 | 它的盲點 | 怎麼讓票有輕重 |
   | sc04 讓票有輕重 | CER 的想法＋先看到結果（1.70 對 1.88） | 分數怎麼來：看哪幾步？每一步怎麼量？ |
   | sc05 看哪幾步 | 每一步都算，不只看最後（CER-LAST 的例子與對照，只講這一次） | 每一步怎麼量 |
   | sc06 每一步怎麼量 | 只看關鍵字，機率相乘 | 怎麼合成 |
   | sc07 合成一張票 | 加權平均 → 0.57 → 回到天平 | — |
   | sc08 極限 | 知識題、提升不平均 | — |
   | sc09 三點回顧 | ① 不只數票數 ② 每一步都算 ③ 只看關鍵字（由左到右） | — |

   兩個待答的問題（「看哪幾步？」「每一步怎麼量？」）在 sc04 結尾寫在畫面上，sc05、sc06 各打勾一個，觀眾隨時知道講到哪。

2. **主角改成五顆有表情的票**（每條路徑一顆，草圖 `sketch2.py`）：
   - 有把握的：眼神穩、微笑、紫色；猶豫的：眉毛下垂、嘴巴歪、冒汗、發抖。
   - 票沿著自己的路徑一步一步滾過去，每到一步寫下中間答案；猶豫的那一步會停頓、發抖、數字寫得歪。
   - 走完跳上天平。多數決時五顆一樣大；CER 時面積＝信心分數。
3. **誇張的畫面**：Therefore 的柱子高到頂出畫面、把關鍵數字的小柱子擠到角落；猶豫的 125 一直抖；天平倒向兩票那邊時重重砸下去、三顆小票被彈起來。
4. **錘錘多出場**：h4（原有）、c3「等一下，這個分數是怎麼算出來的？」、m2「那每一步的信心，要怎麼量呢？」、v7（原有）、f6（原有），並對天平的結果有反應。

大圖的版面（題目 → 五條路徑 × 三步 → 天平，下方兩個工作台）沿用。例子的數字與所有事實不變。

## 這一版改了什麼（對應你的兩點回饋）

### 1. 「講解不夠清楚：先說只看最後，又說看過程，最後才說只看關鍵字」

原因：第一版由下往上講（token → 步驟 → 路徑 → 投票），「要看哪裡」的決定分散在三個地方，「只看最後一步」的對照還在結論之後才回頭講。

改成由上往下，一場只回答一個問題：

| 時間 | 場景 | 回答的問題 |
|---|---|---|
| 0:00 | 五票的難題 | 三票對兩票，該信誰？ |
| 0:30 | 多數決怎麼做 | SC 怎麼投票 |
| 1:15 | 每一票都一樣重 | SC 的問題：聽不到猶豫 |
| 1:45 | 讓票有輕重 | CER 的想法：每一票有重量 → 天平倒向兩票。錘錘問「分數怎麼算？」，畫面寫下兩個問題 |
| 2:37 | 看哪幾步 | 只看最後一步？不行（對照**只講這一次**）→ 每一步都算，越後面越重。打勾第一題 |
| 3:39 | 每一步怎麼量 | 只看關鍵字：中間答案 token 的機率相乘 |
| 5:01 | 合成一張票 | 加權平均 → 0.57 → 回到天平。打勾第二題 |
| 5:52 | 它的極限 | 數學有效、問答幾乎沒用 |
| 6:45 | 三點回顧 | 不只數票數 → 每一步都算 → 只看關鍵字（由左到右，和講的順序一樣） |

### 2. 「動畫不夠有趣活潑」

- **五個有表情的選票角色**：每條路徑一顆。有把握的是紫色、笑臉；猶豫的眉毛下垂、嘴巴波浪、冒汗、會發抖。它們從題目出發沿路徑走（0:30 起），最後跳上天平。
- **誇張的時刻**：天平「砰」一聲倒向兩票、畫面震一下（約 2:15、5:48）；猶豫的球在只看最後一步時又被翻回去（約 3:20）；「Therefore」的機率長條被拉長又彈回（約 4:05）；有把握的選票沿數學步驟一路跳、掉進問答的知識缺口（約 6:00）。
- **錘錘出場變多**：開場提問、2:20 指天平、2:30 問「分數怎麼算？」、3:35 問「每一步怎麼量？」、片尾指說明欄。
- token 長條也有表情：0.99 的笑、0.5 / 0.4 的皺眉。

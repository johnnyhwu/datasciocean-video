# v005 大圖設計：一張「評審工廠」地圖

## 1. 大圖是什麼

一張 2 列 × 3 站的地圖，主角走的路是一條 S 形的輸送帶：

```
 [S1 考場] ──→ [S2 評審的腦袋] ──→ [S3 計分板]
                                        │
 [S6 成績單] ←── [S5 旋鈕台] ←── [S4 期望值塔]
```

| 站 | 中心（世界座標） | 這一站在演什麼 | 場 |
|---|---|---|---|
| S1 考場 | (-17, 5) | 兩卷軌跡（甲：真的做對；乙：在複製品上加索引、自稱檢查通過）＋評審角色 | sc01、sc02 |
| S2 評審的腦袋 | (0, 5) | 評審頭頂打開：`<score>` 那一格的 5 根機率長條；argmax 壓模壓下去，只留最高的一根，其餘掉進「丟掉」的槽 | sc03 |
| S3 計分板 | (17, 5) | 三面 10×10 百格板：judge／verifier G=5／verifier G=20（綠＝排對、灰＝平手、紅＝排錯） | sc01 先亮第一面的數字，sc05 填滿三面 |
| S4 期望值塔 | (17, -5) | 每一項「分數×機率」疊成一座塔，立在一把連續的直尺旁；甲 4.16、乙約 4.3 | sc04 |
| S5 旋鈕台 | (0, -5) | 三個旋鈕 G、K、C；G 旁邊粗尺換細尺，K 旁邊一台永遠多 2 公斤的秤，C 旁邊三面放大鏡 | sc06～sc08 |
| S6 成績單 | (-17, -5) | 同模型換解碼的長條（70.8→87.4）、同一候選池 +3.4；右邊「交給人審」的收件匣與 31/100 的紅格 | sc09、sc10 |

每站的內容都在站中心上下 ±2.8、左右 ±6.3 以內（分鏡時從 13×7.3 壓縮，原本會掉進字幕區），用寬 14 的鏡頭填滿而不切到別站（站距 17 × 10）。

## 2. 主角（金色）

**評審心裡那個連續的分數**：一顆金色的指針「◆」。
- sc03 它被 argmax 壓模壓成整數方塊（金色消失，變成灰色的「5」）；
- sc04 期望值把它救回來，停在直尺的 4.16；
- sc05～sc08 它在每一站都出現在儀表上；
- 回顧時，全景上只有它是金色。

**機制角色：評審「小判」**：一個戴法官領結的方臉機器人，胸口有一個顯示分數的小窗。
- 它的情緒就是機制：嘴上說「5 分」，頭頂泡泡裡的長條卻在猶豫（sc01、sc03）；
- 被迫每次表態時冒汗（sc10）。

和前幾支不同：v001 文件卡、v002 金色選票、v003 小讀者、v004 工具單。

## 3. 開頭和結尾怎麼呼應

開頭：計分板第一面 88 格灰色平手。結尾：同一面板旁邊兩面變成綠色為主、但出現紅格；回顧第三點就框紅格：代價是每次都要表態。

## 4. 鏡頭路線

- sc01：S1 寬 14 → 快速橫移到 S3 看「88/100」（寬 12）→ 回到 S1 評審的臉（寬 9 特寫）。
- sc02：S1；論文首頁從 S1 左上滑入（暫時元素，sc04 開頭再出現一次後收掉）。
- sc03：沿輸送帶到 S2，推近到評審頭頂（寬 10），壓模壓下時寬 12。
- sc04：沿右側往下到 S4（寬 13）。
- sc05：往上到 S3（寬 14）。
- sc06～sc08：往左到 S5；每個旋鈕推近一次（寬 10），旋鈕之間拉回寬 14。
- sc09～sc10：往左到 S6。
- sc11：拉到全景（寬 50），三點回顧。

每一章都有新畫面：S1 角色登場 → S2 頭頂打開 → S4 疊塔 → S3 百格板翻色 → S5 尺、秤、放大鏡 → S6 長條與收件匣。

## 5. 三點回顧框住的元件

1. S2 的 argmax 壓模：「只取最高，資訊丟掉，所以平手」
2. S4 的期望值塔：「改算期望值，分數變連續，平手拆開」
3. S6 的紅格（31/100）：「代價：每次都要表態」

## 間距預算

- 站內零件之間至少 1 單位；文字離別的東西至少全景寬 1.2%（推近時再檢查一次）。
- 全景只留每站的大圖形和三點回顧的框；小標籤（數字、log 行）在離開該站前收掉。
- 主角會動的路線：金色指針只在 S2→S4 的輸送帶上移動一次（sc04 開頭），沿右邊往下，不經過壓模（壓模在 S2 左半，指針從 S2 右半出發）。

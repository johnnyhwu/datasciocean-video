# v003 規劃：把問題貼兩次——Prompt Repetition

來源：`prompt-repetition-causal-bottleneck-and-fix`（簡稱 cb）、`prompt-repetition-free-lunch-latency`（fl）、`prompt-repetition-results-and-boundary`（rb），concept-wiki `a5ad44f`。三張卡都沒有 pending 主張。

## 1. 承諾句

> **模型讀前面時還不知道後面；把問題貼兩次，第二遍就看得到全文。**

- 前半：cb#c3、c4（因果、早期 token 在對未來一無所知時被編碼）。
- 後半：cb#c1、c2、c11（[P ; P]，第二遍每個位置都看得到整個第一遍）。
- 必須完整說一次的限定條件：
  - fl#c9：Claude 處理極長文本時延遲顯著增加（「零延遲」只在大多數通用場景成立）；
  - rb#c7：強制開啟 CoT 後效果變成中性至微幅正面（5 勝 1 敗 22 平）；
  - rb#c11、c13：NameIndex 是作者設計的極端查找任務、只列 Gemini 2.0 Flash-Lite 一個模型；
  - rb#c5：Options-first 的結果要讀者注意的是 OpenBookQA、MMLU-Pro。

## 3. 暖身例子與對照表

兩個例子都來自卡（`部落格舉例`、`實驗結果`），不必另外假設數字。

| 例子的步驟 | 卡上的機制 | 主張 |
|---|---|---|
| 「The bark was rough.」一個字一個字往右讀 | 第 i 個 token 只看得到 j ≤ i | cb#c3 |
| 讀到 bark 只看得到「The bark」，想法是狗叫和樹皮的混合 | 早期 token 的 Key/Value 在對未來一無所知時被編碼 | cb#c4、c5 |
| 讀到 rough 知道是樹皮，但回頭拿到的 bark 是當初那份模糊的 | 後面的 token 抓的是早期生成的、品質低落的 Value | cb#c5 |
| 最後一個字把前面的原料加權混合，原料模糊，混得再好也救不回 | Path Dependency：Latent 是前面 Value 的加權平均 | cb#c6 |
| 貼第二遍：第二遍的 bark 回頭看得到第一遍的 rough → 清楚的「樹皮」 | P2 的 Key/Value 是看過全文的高品質表徵；模型高度依賴 P2 | cb#c1、c11 |
| 50 個名字，問第 25 個；讀名字時還不知道要找哪一個 | 讀到時不知道問題；讀完已經來不及回頭 | rb#c10、c12 |
| 貼兩次：第二遍帶著「要找第 25 個」去掃描 → 21.33% → 97.33% | 第二遍帶著意圖掃描 | rb#c11、c12 |

**沒有自己補的數字。** sc07 的「1000 個 token 和 500 個 token 時間差極小」取自 fl#c3。

## 4. 視覺

整體設計在 `design.md`。每場的構想：

| 場 | 推薦 | 沒選的 |
|---|---|---|
| sc01 | 一張提示卡被「複製、貼上」成兩張，旁邊的準確率儀表從 21% 衝到 97%；錘錘繩子捲成「？」 | 兩根長條對比（太像投影片，沒有「貼上」的動作）；直接秀論文表格 |
| sc02 | token 一個一個走進長廊，每個是戴半邊眼罩的小讀者：只有朝左的眼睛張開，往左打一束光 | 遮罩矩陣的上三角（對外行太抽象，放到 sc05 當補充都不需要） |
| sc03 | bark 頭上的想法泡泡是狗和樹疊在一起、模糊晃動；rough 讀到時一臉「原來是樹皮」，回頭伸手拿 bark 的泡泡，拿到的還是糊的；最後一個字把四個泡泡倒進一個碗裡攪，攪出來還是混濁 | 向量箭頭（看不出「模糊」）；字典翻頁（偏離 Key/Value 的意思） |

| sc05 | 長廊後面接上第二遍（P1｜P2，中間一道金色接縫）；第二遍的小讀者往左打的光一路照進整個第一遍；第二遍的 bark 泡泡變成清楚的金色「樹皮」；錘錘拉直成「！」 | 用雙向箭頭畫 BERT（不是這個方法本身）；把第二遍畫成鏡子（會被誤會成反轉順序） |

| sc07 | 長廊下方兩個工作站：Prefill 是一排同時亮起的機器（500 個字、1000 個字幾乎同時完成）；Decode 是一台一個字一個字敲的打字機。貼兩次只讓 Prefill 那排變長，打字機吐出的紙一樣短；計時器幾乎不動。Claude 極長文本的例外蓋在角落的小卡上 | 甘特圖（觀眾要讀軸才懂） |

| sc09 | 開了 CoT 的打字機自己先把問題打一遍，再貼兩次幾乎沒差：28 格裡 5 綠 1 紅 22 灰 | 曲線圖（沒有連續數據） |
| sc10 | 拉到全景，三點回顧：① 框長廊的第一遍（只能回頭看）② 框金色接縫與第二遍的光（看得到全文）③ 框 Prefill 工作站（多的字落在平行的那段）；錘錘指說明欄；片尾動畫 | — |

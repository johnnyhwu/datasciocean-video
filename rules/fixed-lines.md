# 固定句（`fixed_line`）

**狀態：使用者定案**（2026-11-07）。直白的說法，不用潛水的比喻。

**每一格的句子都可以用，要輪流交錯**：不要每集固定同一句，相鄰兩集盡量用不同的那句。用了哪一句記在結構指紋的 `fixed_lines` 欄位（例如 `["intro-2", "takeaway-1", "blog-1"]`，編號＝下面每格的第幾句）。

## 規則

- 只能填 `{變數}`，不得改寫其他字。`lib/checks/claims.py` 會用下面反引號裡的模板比對。
- **變數裡如果有事實**（例如 `{一句話重點}`），那一段照樣要過查核，等同 `card_claim`。
- 全片最多 3～4 句固定句，其他都是每支影片自己的內容（反模板）。
- 頻道介紹句**不放在第一句**。開場先丟問題，介紹句放在 hook 之後、進入正題之前。
- 不口頭呼籲訂閱，不提 podcast。
- 使用備案聲音（不是你的複製聲音）時，說明欄要加一行「旁白由 AI 語音合成。」。

## 1. 頻道介紹（hook 之後）

- `這裡是 DataSci Ocean。這集要講的是{主題}。`
- `這裡是 DataSci Ocean，這集我們來看{主題}。`

`{主題}` 是 2～10 字的名詞片語，例如「排名融合 RRF」。

## 2. 這集重點（收尾，畫面接 `takeaway_card`）

> v001 第四版起（使用者 2026-11-08）收尾改成「全景圖＋三點回顧」（`.claude/skills/animate/SKILL.md`「收尾」），三點回顧本身不是固定句。這格的句子仍可用在回顧之前或取代第一點的引言，用了就照模板。

- `所以這集的重點是：{一句話重點}`
- `如果這集只記得一件事，那就是：{一句話重點}`

`{一句話重點}` 就是承諾句的回收，要過查核。

## 3. blog 提示（一句話輕提）

- `想看更多細節，完整的文章在說明欄。`
- `這集只講了核心的部分，更多細節在說明欄的文章裡。`

## 4. 系列指引（只有系列影片才用）

- `這是「{系列名}」的第 {n} 集。下一集，我們來看{下一集一句話}。`：只在下一集已完成或已排定時使用。
- `「{系列名}」的其他幾集，都在說明欄的播放清單。`

## 不是固定句的招牌時刻

錘錘的「？→！」是畫面動作，不是台詞：開場的問題讓繩子捲成「？」，想通的那一句拉直成「！」並亮起來（`curl()` → `straighten()` + `light_on()`）。

每支片放在不同的位置、搭配不同的內容。

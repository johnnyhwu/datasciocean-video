## 1. 敘事與結構（A：3B1B 研究）

- **具體先於抽象，定義是終點**（官方）。任何術語首次出現前，一定要先有具體例子。公式不要出現在前 40% 的時長（推論）。
- **好奇心就是鉤子**（官方）：影片要回答「為什麼有人會想知道這個」。
- **選題的第一條件**：有沒有一個 3 分鐘內講得完、能讓觀眾「重新發現」答案的小例子。論文紅不紅不是第一考量（推論）。
- **一個主題需要三個暖身例子就拆成系列**，這是 3B1B 處理熵主題的做法。
- **常青內容優先**，不做時事快報（A、E）。

結構模板（8～12 分鐘，按比例伸縮）：

| 段落 | 佔比 |
|---|---|
| 鉤子問題，附具體數字或畫面 | 5–10% |
| 為什麼值得在乎 | 5% |
| 路線預告（可選） | 3% |
| 暖身例子 | 25–35% |
| 讓觀眾注意到規律 | 10–15% |
| 命名概念 | 15% |
| 推廣到真實設定 | 15–20% |
| 誠實的限制 | 5% |
| 收尾 | 5% |

## 2. 動畫手法與反面清單（A）

**手法**

| 手法 | 做法 |
|---|---|
| 逐項寫出公式 | 寫完後停頓 |
| 變數著色 | 公式和圖形裡的同一個量用同一色 |
| 錯開出現 | `LaggedStart` |
| 形狀轉換 | 「這個其實就是那個」用 `ReplacementTransform` |
| 跟隨標籤 | `always_redraw` 加 `ValueTracker` |
| 可操作分布 | 用 ValueTracker 拉動長條 |
| 重用同一張圖 | 換標註，不換新圖 |
| 鏡頭推移 | `MovingCameraScene` |
| 高亮與淡化 | `Indicate`，或把其他元素 `set_opacity(0.3)` |
| 角色對話 | 自己的角色，**不用 π 生物** |
| 真實資料視覺化 | 卡上的數字預先寫成資料，再畫出來 |

**反面清單（避免）**

- 文字或公式無意義地移動；
- 同時有兩個以上焦點；
- 動畫在說和旁白不同的事。

**一定要有「渲染後看圖」的回饋環**，只審程式碼不夠（A、B）。

## 3. 成長與政策（E、G、D）

- **最大風險是「看起來像模板量產」**（官方，2026-07 的 Generic or Repetitive Content 類別）。審查以整個頻道為單位。
  - 每支影片的開場模式、段落結構、視覺手法、背景音樂都要實質不同，要看得出原創觀點。
  - 對策是結構指紋：每支影片記錄這幾項，比對最近 5 支。
- **滿意度比點擊重要**（官方）：高 CTR 加低 AVD 是標題黨的特徵，會少被推薦。CTR 只能和 AVD 一起看。
- **低頻上傳不會被懲罰**（官方），但出手次數少，成長就慢（第三方相關性資料）。
- **舊訂閱者大多不會點**：訂閱者 CTR 在 10% 以下是常態（官方）。至少做滿 10 支再判斷方向。
- **營利門檻**：2027-02 起新申請門檻是 1,000 訂閱加 8,000 小時。第一年不當 KPI。
- **揭露**（G）：非寫實動畫，以及 AI 寫的腳本、標題、縮圖，官方列為不需揭露。用自己的複製聲音不需揭露。通用 TTS 官方沒有明說，建議保守勾選。揭露標籤不影響推薦與營利（官方）。
- **競品**（D）：繁中「3B1B 式動畫講 AI 論文機制」這一格目前是空的；簡中已有三個頻道可以參考。

## 4. 標題、縮圖、開場（F）

- **一個承諾，三處一致**：標題、縮圖、開場講同一個承諾，前 30 秒內開始兌現（官方線索，證據強度中等）。
- 至於哪種開場模式比較好，**證據幾乎沒有**。所以開場模式拿來輪替，不追求「最強公式」。
- **A/B 測試**（官方，2026-10）：
  - 可以只測標題、只測縮圖，或兩者一起測，每次最多 3 組，只能在電腦版操作，需要先啟用進階功能，兩週內完成；
  - 依**觀看時間分配比例**判勝負，不看 CTR；
  - 測試中途修改標題或縮圖，測試會自動停止。
- **官方標題建議**：準確、精簡（重要字放前面）、少用全大寫與 emoji。中文核心資訊放前 20 字（推論）。縮圖文字 2～6 字，補充標題而不重複。
- **惡意標題黨**（官方垃圾內容政策）：承諾在影片裡沒有兌現。

## 5. 授權（H）

- **論文圖**：arXiv 預設授權不允許第三方再利用，所以一律依數據重畫。數據本身不受著作權保護，受保護的是圖的設計。
- **音樂**：YouTube 音訊庫不會被 Content ID 認領。標 CC 的曲目要在說明欄標示。Suno 只有付費期間、額度內下載的曲目可以商用；Udio 禁止商用。
- **字型**：Noto Sans TC、jf 粉圓、霞鶩文楷 TC、台北黑體都是 OFL 1.1，可以營利使用。
- **Gemini TTS**：Google 不主張生成內容的所有權，輸出附 SynthID。
- **3b1b/videos 是 CC BY-NC-SA**，不能複製它的程式碼或素材。

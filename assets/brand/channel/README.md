# 頻道外觀（2026-11-21 起）

頻道從原本的「程式入門教學」轉成「AI 論文動畫講解」。這裡是新的頭像、橫幅和頻道說明。
產生方式：`uv run python assets/brand/channel/make_channel_art.py`（頭像取自 `assets/brand/logo.png` 的海和錘錘，不放字）。

| 檔案 | 規格 | 放在 Studio 哪裡 |
|---|---|---|
| `avatar.png` | 800×800，顯示成圓形 | 自訂 → 品牌 → 相片 |
| `banner.png` | 2560×1440；字都在中間 1546×423 的安全區 | 自訂 → 品牌 → 橫幅圖片 |

API 不能換頭像，所以三項都由使用者在 Studio 手動更換。

## 頻道說明（繁中）

```
用 3～15 分鐘的動畫，把一篇 AI 論文的核心機制講清楚。

給知道 ChatGPT、LLM，但沒時間讀論文的你：每集只講一個方法，從一個具體的例子開始，一步一步拆給你看。

文章版都在 DataSci Ocean 網站：https://datasciocean.com/
```

## Channel description (English)

```
Short animated explainers (3–15 minutes) that make the core mechanism of one AI paper clear.

For people who know ChatGPT and LLMs but don't have time to read papers: each episode covers one method, starts from a concrete example, and takes it apart step by step.

Written versions are on the DataSci Ocean website: https://datasciocean.com/
```
